# 需求起点

来源：初始化配置 + 2026-11-09 夜班本病种立项（2026-11-10 修正：原文件是 FSHD 模板残留，已按 CAD 口径重写）。用户、场景和流程是有效的 SPEC 互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：确诊或拟诊冷凝集素病（CAD）的成人患者本人，以及协助录入的家属照护者；含继发于淋巴增殖性疾病的转诊随访人群、需要反复输血与滴度复测的人群。

场景：溶血化验（Hb、LDH、间接胆红素、网织红）与冷凝集素滴度复测留痕；寒冷诱发发作（手指/耳廓发紫、肢端疼痛、活动后气促）的诱因、部位与持续时间记录；输血按次登记（成分、机构、加温输血等医生原话）；基础病与确诊依据档案；用药与复诊问题清单；就诊前摘要导出（私密项过滤）。

核心流程：
1. 选择本机资料目录并登记化验单、出院小结等原件
2. 抄录关键化验与滴度结果，标注方法/单位/机构，未知项留空
3. 记录一次发作的诱因、表现、持续时间与缓解开始，行动计划只照抄医生原话
4. 按次登记输血与治疗，保留特殊处理要求原话
5. 查看指标卡与一图秀，生成复诊前摘要

完成结果：得到来源可追溯、可核对的个人病程档案：确诊依据与基础病、溶血/滴度/血象/体征指标、发作—缓解时间线、输血与治疗记录、复诊问题清单；所有候选信息经用户核对入档，不提供诊断、疗效判定、用药剂量或阈值解读。
