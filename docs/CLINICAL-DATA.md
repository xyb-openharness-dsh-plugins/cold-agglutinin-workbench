# CLINICAL-DATA · cold-agglutinin-workbench（v0.1 · 夜间版，M1 扩全）

## 内容边界（指南定边界，不转自测）
- CAD = 冷抗体型自身免疫性溶血性贫血（cAIHA）主要亚型；特征：冷反应性自身抗体、受累部位（耳/鼻/手指等暴露部位发绀）、寒冷加重
- 继发性关联：淋巴增殖性疾病（如淋巴瘤）、感染（支原体、EBV 等）——档案页只录医生给出的原话
- 随访化验组：血常规（Hb）、网织红细胞、LDH、结合珠蛋白、间接胆红素；冷凝集素滴度；DAT（C3）
- 输血相关：医生交代的特殊处理（加温输血、保温送检）只照抄原话；不写具体温度阈值（【待核】）

## 指标体系（本台分组，≥4 组；阈值一律【待核】）
1. 溶血指标：Hb / 网织红% / LDH / 结合珠蛋白 / 间接胆红素
2. 冷凝集素滴度：滴度值（方法与实验室可比组标注）
3. 血象与铁代谢：WBC / PLT / 铁蛋白（按医嘱）
4. 体征：体重 / 血压 / 体温（发作时）
