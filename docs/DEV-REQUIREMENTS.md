# DEV-REQUIREMENTS · cold-agglutinin-workbench

## 一、患者视角红线
- 功能按患者关心维度组织：化验怎么看、为什么冬天更难受、输血要注意什么、下次复诊问什么；医生任务不冒充患者需求（独立评审一票否决项）
- 患者原话：0 访谈，全部为设计假设并标注「待访谈核实」，不冒充一手引语

## 二、事实与来源红线
- 医学阈值（滴度参考范围、输血加温温度、DAT 分型解读）一律【待核】占位 + 来源行，不写自动判定
- 指南只定内容边界：发作—缓解、受累部位、随访节律；不转自测或选治疗
- 中国适应证/规范只认中国官方来源（卫健委罕见病指南等），国际来源标注「二次来源·未取得原件」

## 三、裁剪声明（可执行验收：设置·临床数据库 tab 有此行）
- 临床试验线裁剪：CAD 患者池极小（万级以下）、统一检索通道对罕见血液病召回不可靠；本台不建试验匹配线，设置 tab 如实写「本台未接入临床试验快照（裁剪，理由见 DEV-REQUIREMENTS §三）」，不静默缺失

## 四、可执行验收约定
- 「两套演示数据联动」= A/B 切换后页头档案名、看板、指标、时间线、导出抽查 3 处不串档（探针断言）
- 「私密过滤」= 看板摘要/导出/AI 上下文三处各造 1 条私密记录实测（测试断言）
- 「阈值待核」= 全站 grep「待核」≥1 且 grep 自动判定类话术（如「你已进入」「属于 N 级」）= 0

## 五、可回退默认值（夜间无人值守 · 待晨审追认）
1. 服务主体：确诊/拟诊 CAD 成人患者，家属协助（不覆盖儿童/代记）
2. 病程覆盖：确诊后全病程，含继发病因转诊随访
3. MinerU：不接入（六部件形态就位、如实标注「勾选与保存不联网」）
4. 品牌占位名：小暖宝 WarmPal（发布前由用户定夺）
5. AI 原生对话：演示态，未接入宿主时明说
