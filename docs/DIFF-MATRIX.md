# DIFF-MATRIX · cold-agglutinin-workbench（v0.1）

对移植样板 pericarditis-workbench（v0.1.2 客户端链路底本）与 breast-cancer v0.4 / aml v0.2（元素体系基准）的差异矩阵。一级功能重名率目标 ≤70%，实测见 M1 附记。

| 维度 | 移植样板（心包炎） | 本台（冷凝集素病） | 验收怎么验 |
| --- | --- | --- | --- |
| 核心随访对象 | 复发次数与心包症状 | 溶血化验组 + 冷凝集素滴度周期复测 | 指标目录分组名逐字：溶血指标/冷凝集素滴度/血象/体征 |
| 事件泳道事件型 | 用药/就诊/检查/缓解开始/加重 | 寒冷暴露/发作开始/缓解开始/输血/就诊 | 时间线类型枚举 grep |
| 看板大状态 | 缓解期第 N 天 | 缓解期第 N 天 +「距上次发作 N 天 · 近 90 天发作 N 次」 | 看板文案探针 |
| 输血线 | 无 | 输血按次登记（成分/机构/加温等特殊处理原话） | 输血页表单字段数与三态按钮 |
| 行动计划 | 急性加重求助短语（医生原话） | 防寒行动计划（医生原话：「若出现 X 联系 Y」） | 不生成、不改写断言 |
| 临床试验线 | 裁剪（非肿瘤） | 裁剪（池过小，§三声明） | 设置 tab 裁剪行存在 |
| 禁词 | 心包/CRP/effusion 0 命中 | 本台词（分期/线序/疗效/生存期/心包）0 命中 | check-schema-words + 全站 grep |
