# INTERACTION-DESIGN · cold-agglutinin-workbench（v0.1 · 对应 28 号 IP1）

## 交互路径（IP 文档 · 版本 v0.1 · 本签认 = 夜间自动签认）
- 每个一级页（8 个业务页 + 设置弹层）至少 1 条路径；(view,sub) 全覆盖，孤儿页=0（IP2 探针）
- 入口名=界面文案=导航 key（IP3）：看板 / 档案 / 指标与趋势 / 发作与诱因 / 输血记录 / 感受笔记 / 资料库 / 临床试验（裁剪说明态）/ 设置
- 每条路径有可观察产物 + 一步回首页（IP4）
- AI 候选通道：档案/化验/发作/输血/笔记 五实体（IP5）；候选核对前不入图（MT10）
- 显式编辑入口每页 ≤1（IP6）；数字输入 inputmode=numeric（IP7）；更正=新版本（IP8/9）
- 每页「和 AI 讨论」携带本页事实上下文，不含判定词（IP10/11、Q19）

## 状态机
- 大状态：发作中 ↔ 缓解期第 N 天（由最近发作/缓解事件推算，读时算）
- 面板：AI 右侧 25–45% 可拖；整页视图（发作详情/原件查看）走 history 栈
