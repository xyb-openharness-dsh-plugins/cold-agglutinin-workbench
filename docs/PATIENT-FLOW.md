# PATIENT-FLOW · 冷凝集素病患者主流程（设计假设 · 0 访谈）

1. 确诊期：医生告知「冷凝集素病/冷抗体型自身免疫性溶血性贫血」→ 患者手里有滴度化验单、DAT 报告，看不懂 → 在档案页抄录关键字段（医生原话+日期），不知道的留「未知」
2. 冬季/冷暴露日常：洗手、开冰箱、喝冷饮后耳朵/手指发紫发麻 → 发作页记一条「寒冷暴露→发作开始」，好转后记「缓解开始」→ 看板显示缓解期第 N 天
3. 复查周期：按医生安排抽血（Hb/网织红/LDH/胆红素，有时加滴度）→ 指标页录入 → 趋势图看「较上次」变化（不判定好坏）
4. 贫血加重时：医生安排输血 → 输血页按次登记，医生交代的特殊要求（如加温输血、血样保温）照抄原话 → 下次就诊前把「输血注意事项」带在摘要里
5. 就诊前准备：复诊问题清单 + 导出摘要（私密过滤）→ 见医生

每步在 SCENARIOS.md 有对应场景 ID，全部路径走 IP2 覆盖断言。
