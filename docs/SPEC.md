# SPEC · 小暖宝 WarmPal 冷凝集素病工作台（v0.1 草案 · 夜间无人值守 · 待晨审追认）

## 一句话
把散落在各医院的溶血化验、冷凝集素滴度复测、寒冷诱发事件、输血记录与医嘱原话整理成一本「来源可追溯、不替医生下结论」的个人病程档案。

## 问题与最小闭环
- 输入：化验单/出院小结照片登记（原件+字段抄录）、发作事件、输血按次记录
- 动作：手工录入（唯一事实通道，M5 起开放导入与 AI 候选）；查看趋势（一图秀）与发作—缓解时间线
- 输出：指标卡+趋势图+最近报告表、可导出的就诊前摘要（私密过滤）
- 失败恢复：更正=新增版本，不裸删除
- 成功标准：患者复诊前 3 分钟能回答「Hb 和 LDH 从上次到现在怎么变、最近发作几次、输血有什么特殊要求」

## 服务主体（默认值，待追认）
- 主体：确诊/拟诊 CAD 的成人患者本人；家属协助录入
- 病程覆盖：确诊后全病程（含继发于淋巴增殖性疾病的转诊随访）
- 不做：诊断、疗效判定、用药剂量建议、滴度阈值自动解读

## 功能范围（一级页面）
1. 看板（今日状态：缓解期第 N 天 / 发作中；医生原话状态句；快捷卡三连；最近报告表）
2. 档案（确诊依据与继发病因登记：冷凝集素滴度、DAT 分型、基础病——只录医生原话与日期）
3. 指标与趋势（溶血组/滴度组/血象组/体征组指标卡 3D 翻转 + 一图秀）
4. 发作与诱因（发作登记：诱因暴露/部位/持续时间；缓解开始；行动计划=医生原话）
5. 输血记录（按次：日期/成分/机构/特殊处理原话如「加温输血」；复诊问题清单）
6. 感受笔记（症状与生活影响，默认私密开关）
7. 资料库（原件登记、最近报告表、导入占位）
8. 临床试验（本台裁剪：CAD 患者群小、快照通道可靠性未验证 → DEV-REQUIREMENTS §三 如实裁剪；设置·临床数据库 tab 保留快照状态位）
9. 设置（弹层三 tab：工作区/文档解析 MinerU/临床数据库）

## 数据与 API
- 事实层：档案/指标/发作/输血/笔记/资料 六实体 + 更正版本链；候选层与事实层分表
- 派生值（缓解期第 N 天、较上次差值）读时算不落库；无 diagnosis/risk_level 判读列
- 时区本地；单位随录入原样保存并标注

## 口径
「仅回顾，不解读」「不同方法/机构不合并」「解读归医生」「阈值【待核】以医生安排为准」
