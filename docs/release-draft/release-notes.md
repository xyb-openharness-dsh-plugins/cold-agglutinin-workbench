# 小暖宝 WarmPal 冷凝集素病工作台 v0.2.0

首个开发版：冷凝集素病（CAD）患者的本机病程档案工作台。

- 看板状态卡（发作中/缓解期第 N 天，由记录算出）、发作—诱因登记、输血与治疗按次登记（特殊要求照抄医生原话）
- 溶血指标/冷凝集素滴度/血象/体征四组 3D 指标卡 + 一图秀（可比组不合并）
- 四段整页疾病概要（定义/指南情况/治疗全景/发展趋势，来源行四态登记）
- 两套合成演示档案；私密三出口过滤；临床试验线如实裁剪（声明见设置·临床数据库）
- 全部阈值【待核】；0 患者访谈、0 临床审核如实标注
- 装机：DSH Desktop → 按会话打开工作台
